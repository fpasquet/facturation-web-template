# facturation-web

Interface de facturation d'exemple, pour essayer des agents de code sur un vrai dépôt : la liste des factures et un
formulaire pour en émettre une, servis par `facturation-api`, le dépôt de son API.

Ce dépôt est un **modèle** : créez le vôtre avec « Use this template », sous le nom `facturation-web`, sur votre
organisation ou votre compte.

```bash
make install    # dépendances, et .env depuis .env.example
make dev        # l'interface sur http://localhost:3010 (lancer aussi facturation-api)
```
